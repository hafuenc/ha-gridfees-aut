# Gridfees AUT 0.6.1

Add **WiNAP active**, a separate winter status indicator enabled by default.

- On only while the optional WiNAP simulation applies to the current hour.
- Off when simulation is disabled, outside the winter window, or for EEG profiles.
- Unavailable outside supported tariff dates, like the other price/status entities.
- Added automatically to existing profiles without changing their entity IDs.
- Total grid fees, SNAP active and WiNAP active are enabled by default; the five
  detail price sensors remain disabled by default for new profiles.

Install the HACS update and restart Home Assistant. No profile recreation is
needed. The WiNAP simulation setting remains off unless explicitly enabled through
Reconfigure; enabling the indicator itself does not enable simulated prices.
Refresh the browser after updating to avoid cached setup translations.
