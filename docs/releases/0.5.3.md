# Gridfees AUT 0.5.3

First HACS release for initial installation and updates.

- Configure Austrian grid areas and regular, local EEG, or regional EEG supply.
- Total grid fees in EUR/kWh excluding VAT, with a rolling seven-day forecast.
- Official German names for grid areas, taxes, fees, and contributions.
- Detail sensors disabled by default; Total grid fees and SNAP active enabled.
- Automatic Elektrizitätsabgabe exemption for allocated EEG energy.
- Corrected integration type: Gridfees AUT is visible in Add integration again.
- Household tax help links use Home Assistant description placeholders.
- Forecast attributes group consecutive hours with equal prices into one period;
  a new row starts only when the total price changes (for example at SNAP boundaries).

## Installation and updates

Requires Home Assistant 2026.3 or newer. Add `hafuenc/ha-gridfees-aut` as an
Integration under HACS custom repositories, download Gridfees AUT, and restart
Home Assistant. Then use Settings → Devices & services → Add integration.

Existing manual installations can be taken over by HACS. Keep the existing
`gridfees_aut` folder and configured profiles, download this release through
HACS, and restart Home Assistant. Existing entity IDs and settings are preserved.

If already running 0.5.2 manually, this release adds HACS management without
changing the tariff calculations. See the README for setup and legal sources.
